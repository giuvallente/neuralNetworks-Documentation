# Artificial Neural Networks & Deep Learning

This site tracks coursework from a class on Artificial Neural Networks and Deep Learning, using PyTorch as the main framework. It covers the mathematical foundations of learning, core architectures (MLPs, CNNs, Transformers), attention mechanisms, generative models (GANs, VAEs, Diffusion, Flow Matching), Diffusion Transformers, and Large Language Models.

## Learning objectives

By the end of the course, the goal is to:

- **Explain the fundamentals** — gradient descent, backpropagation, activation functions, and regularization.
- **Describe key architectures** — MLPs, CNNs, Transformers, and LLMs, and why they're built the way they are.
- **Implement with PyTorch** — train and debug deep learning models.
- **Evaluate performance** — apply the right metrics and regularization/optimization techniques.
- **Work with generative models** — GANs, VAEs, Diffusion, and Flow Matching.
- **Apply transfer learning** — fine-tune pre-trained models using PEFT techniques (LoRA, QLoRA).
- **Understand LLMs** — their architecture, training methods (RLHF, DPO), and applications.
- **Critically evaluate research** — read and assess current deep learning papers.
